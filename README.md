# Hi, I'm Marco 👋

Developer advocate and engineer. I've been building on blockchains since 2017: SDKs, dev tooling, smart contracts, docs, and lately the AI tooling that helps developers (and their agents) get things right on the first try.

## Selected work

**Internet Computer · DFINITY** (Senior DevRel, 2024–2026)
- [icskills](https://github.com/dfinity/icskills): agent-readable skill files for ICP development that stop AI coding assistants from hallucinating APIs
- [icp-cli](https://github.com/dfinity/icp-cli), [templates](https://github.com/dfinity/icp-cli-templates) and [recipes](https://github.com/dfinity/icp-cli-recipes): the next-generation developer CLI and its project scaffolding
- [developer-docs](https://github.com/dfinity/developer-docs) and [examples](https://github.com/dfinity/examples): rebuilt the developer documentation at [docs.internetcomputer.org](https://docs.internetcomputer.org) and maintained the official example apps
- [vetkeys](https://github.com/dfinity/vetkeys), [pic-js](https://github.com/dfinity/pic-js), [icp-js-bindgen](https://github.com/dfinity/icp-js-bindgen): libraries, testing and codegen tooling
- [vetVault](https://github.com/marc0olo/pw-manager-vetkeys) (side project): a password manager on ICP that encrypts in the browser with vetKeys and signs in with Internet Identity, so there is no master password. Vaults can be shared at three permission levels.

**kryptokrauts** (2019–today)

Since 2021: building [Soon.Market](https://soon.market), an NFT marketplace on [XPR Network](https://xprnetwork.org) (Antelope / EOSIO Leap).
- [xpr-contracts](https://github.com/kryptokrauts/xpr-contracts): the `powerofsoon`, `soonmarket` and `nftwatchdao` smart contracts in TypeScript, covering SOON SPOT promotion auctions, collection verification and blacklisting, and automated treasury flows
- [NFT Watch DAO](https://github.com/kryptokrauts/nft-watch-dao): community-governed blacklisting of scam NFT collections and shielding of legitimate ones, enforced on-chain
- [sdcworkshop](https://github.com/kryptokrauts/sdcworkshop): a hands-on TypeScript smart contract workshop at the Social Developers Conference 2024 in Hamburg. Participants earned XPR from an on-chain reward pool by deploying a working homework contract within 30 days.

Before that (2019–2022): the Java SDK for æternity ([aepp-sdk-java](https://github.com/kryptokrauts/aepp-sdk-java)) and a Maven plugin that generates typed Java classes from Sophia smart contracts ([contraect-maven-plugin](https://github.com/kryptokrauts/contraect-maven-plugin)).
